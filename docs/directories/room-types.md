# Типы помещений

Справочник **видов помещений** (например: торговая площадь, склад, офис). Короткие названия-классификаторы, к которым привязывают конкретные [помещения](./premises.md).

Маршрут: `/directories/room-types` · В меню: да

См. также: [обзор раздела](./README.md), [помещения](./premises.md).

---

## Общее описание справочника

### Зачем нужен

Чтобы в списке помещений одинаково классифицировать объекты во всех формах. Справочник простой: одно поле — наименование.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.

Данные: **API** или **mock**. Пагинация на клиенте.

### Какие данные хранит

| Поле в интерфейсе | Обязательно | Пояснение                       |
| ----------------- | ----------- | ------------------------------- |
| Наименование      | да          | название типа (до 255 символов) |

### Связи с другими разделами

- **Используется в:** [помещения](./premises.md) — тип выбирают при создании/правке помещения.
- В дела брокера напрямую не попадает: в дело выбирают уже конкретное помещение (с типом внутри).
