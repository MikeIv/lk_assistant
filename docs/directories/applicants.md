# Претенденты

Справочник **потенциальных арендаторов** (брендов / организаций): название, категория, группа компаний, юрлицо и контакты.

Маршрут: `/directories/applicants` · В меню: да  
См. также: [обзор раздела](./README.md), [категории](./categories.md), [юр. лица](./legal-entities.md), [брокер / дела](../broker.md).

---

## Общее описание справочника

### Зачем нужен

Картотека контрагентов для аренды. В [текущих делах](../broker.md) брокер выбирает претендента из этого списка (нового можно завести и в контексте дела, но база живёт здесь). Без справочника сложно вести историю по одному и тому же бренду/организации.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.  
Данные: **API** или **mock**. В режиме API список **пагинируется на сервере**.

### Какие данные хранит

| Поле в интерфейсе                         | Обязательно | Пояснение                                     |
| ----------------------------------------- | ----------- | --------------------------------------------- |
| Бренд / наименование организации          | да          | как претендента называют в работе             |
| Категория                                 | да          | из справочника [категорий](./categories.md)   |
| Группа компаний                           | нет         | холдинг / сеть, если применимо                |
| Юридическое лицо                          | нет         | из справочника [юр. лиц](./legal-entities.md) |
| Контакты (ФИО, должность, телефон, email) | нет         | несколько контактов на одного претендента     |

### Связи с другими разделами

- **Зависит от:** [категории](./categories.md), опционально [юр. лица](./legal-entities.md).
- **Используется в:** [текущие дела брокера](../broker.md) — выбор претендента в карточке дела.

## Для разработки (кратко)

| Что        | Где                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| Composable | `useApplicants`, `useApplicantForm`                                                                     |
| UI         | `app/components/direct/applicants/` (`Sec`, `Table`, `FormFields`, модалки)                             |
| Shared     | `applicantsNormalize`, `applicantsSchema`, `applicantsTable`, `applicantsValidation`, `applicantsQuery` |
| Mock       | `shared/constants/applicantsMock.ts`                                                                    |
| API        | `/v1/broker/tenant-applicants`, detail `…/tenant-applicants/{id}`                                       |
| Пагинация  | server-side: `page`, `per_page`, `sort`, `direction`, `search`                                          |
| Селекты    | при форме подгружаются категории и юрлица; в делах — `useTenantCaseFormOptions`                         |
