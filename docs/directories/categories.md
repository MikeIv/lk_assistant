# Категория

Справочник **категорий претендентов** — короткие метки, по которым группируют потенциальных арендаторов (например, по формату бизнеса или сегменту).

Маршрут: `/directories/categories` · В меню: да  
См. также: [обзор раздела](./README.md), [претенденты](./applicants.md).

---

## Общее описание справочника

### Зачем нужен

В карточке претендента категория обязательна. Справочник держит единый набор категорий для всего ЛК, без свободного текста каждый раз.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.  
Данные: **API** или **mock**. Пагинация на клиенте.

### Какие данные хранит

| Поле в интерфейсе | Обязательно | Пояснение                            |
| ----------------- | ----------- | ------------------------------------ |
| Наименование      | да          | название категории (до 255 символов) |

### Связи с другими разделами

- **Используется в:** [претенденты](./applicants.md) — категория обязательна при создании/правке.
- В [делах брокера](../broker.md) категория претендента может отображаться, но правится только в справочниках.
