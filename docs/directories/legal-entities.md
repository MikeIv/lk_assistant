# Юр. лица

Справочник **юридических лиц**: официальное наименование, ИНН и КПП. Реквизиты контрагента, в первую очередь для [претендентов](./applicants.md).

Маршрут: `/directories/legal-entities` · В меню: да  
См. также: [обзор раздела](./README.md), [претенденты](./applicants.md).

---

## Общее описание справочника

### Зачем нужен

Претендент часто связан с конкретным юрлицом (ООО, АО и т.д.). Реквизиты хранятся централизованно: ИНН/КПП не набирают заново, проще искать дубликаты.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.  
Данные: **API** или **mock**. В режиме API список **пагинируется на сервере**.

### Какие данные хранит

| Поле в интерфейсе              | Обязательно | Пояснение                          |
| ------------------------------ | ----------- | ---------------------------------- |
| Наименование юридического лица | да          | полное или рабочее название        |
| ИНН                            | да          | идентификационный номер            |
| КПП                            | нет         | код причины постановки (если есть) |

### Связи с другими разделами

- **Используется в:** [претенденты](./applicants.md) — к претенденту можно привязать юрлицо из этого списка.
- Прямого выбора юрлица в карточке дела нет: связь идёт через претендента.
