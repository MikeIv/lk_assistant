# Помещения

Справочник **конкретных помещений** комплекса: номер, этаж, площадь, тип и данные по БТИ. Это основной список объектов, которые брокер выбирает при работе с делами.

Маршрут: `/directories/premises` · В меню: да

См. также: [обзор раздела](./README.md), [типы помещений](./room-types.md), [текущие дела](../broker/current.md).

---

## Общее описание справочника

### Зачем нужен

Без этого справочника нельзя нормально вести переговоры по аренде: в деле нужно указать, **какое именно помещение** обсуждается. Список общий для всего ЛК — один раз завели помещение, дальше оно появляется в селектах.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.

Данные: **API** (если задан `NUXT_PUBLIC_API_BASE`) или **локальный mock**. Пагинация на сервере (в mock — на клиенте).

### Какие данные хранит

| Поле в интерфейсе          | Обязательно | Пояснение                               |
| -------------------------- | ----------- | --------------------------------------- |
| Тип помещения              | да          | из справочника [типов](./room-types.md) |
| Номер помещения            | да          | как помещение называют в работе брокера |
| Этаж                       | нет         | этаж в учёте комплекса                  |
| Площадь                    | нет         | площадь в м²                            |
| Номер / этаж / площадь БТИ | нет         | параллельные сведения по БТИ            |

### Связи с другими разделами

- **Зависит от:** [типы помещений](./room-types.md) — без типа помещение не создать.
- **Используется в:** [текущие дела брокера](../broker/current.md) — помещение выбирают в карточке дела.

## Для разработки (кратко)

| Что           | Где                                                                                           |
| ------------- | --------------------------------------------------------------------------------------------- |
| Composable    | `usePremises`, `usePremiseForm`                                                               |
| UI            | `app/components/direct/premises/` (`Sec`, `Table`, модалки)                                   |
| Shared        | `premisesNormalize`, `premisesSchema`, `premisesTable`, `premisesQuery`, `premisesValidation` |
| Mock          | `shared/constants/premisesMock.ts`                                                            |
| API           | `/v1/broker/dict/rooms`, detail `/v1/broker/dict/rooms/{id}`                                  |
| Пагинация     | server-side: `page`, `per_page`, `sort`, `direction`, `search`                                |
| Опции в делах | `useTenantCaseFormOptions`                                                                    |
