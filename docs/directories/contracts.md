# Договоры

Задуманный справочник **договоров**. В текущей версии ЛК **не реализован**: страница показывает баннер «Раздел в разработке», пункт **скрыт из подменю** справочников.

Маршрут: `/directories/contracts` (доступен по прямой ссылке) · В меню: нет  
См. также: [обзор раздела](./README.md), [юр. лица](./legal-entities.md), [брокер / дела](../broker.md).

---

## Общее описание справочника

### Статус

| Что              | Сейчас                |
| ---------------- | --------------------- |
| Для пользователя | баннер «в разработке» |
| CRUD             | нет                   |
| Данные / API     | нет                   |
| В навигации      | скрыт                 |

### Зачем планировался

Отдельный учёт договоров аренды (номера, стороны, сроки и т.п.) рядом с остальными справочниками. Сейчас договора как сущности фронтенда нет — ни в меню, ни в API-слое ЛК.

### Что важно при планировании

- UI CRUD и бэкенд-контракт не сделаны.
- Реализация потребует согласования контракта с Broker API и состава полей; до этого заглушка остаётся осознанно.
