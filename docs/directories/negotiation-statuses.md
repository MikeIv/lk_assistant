# Статусы переговоров

Справочник **этапов переговоров** по делу: короткие статусы вроде «интерес», «КП отправлено», «отказ» — единый набор для всех дел брокера.

Маршрут: `/directories/negotiation-statuses` · В меню: да

См. также: [обзор раздела](./README.md), [брокер / дела](../broker.md).

---

## Общее описание справочника

### Зачем нужен

В карточке текущего дела брокер отмечает этап переговоров. Статусы должны быть одинаковыми у всей команды — поэтому они в справочнике, а не свободным текстом.

### Что может пользователь

Полный CRUD: список, поиск, сортировка, создание, правка; удаление — из карточки с подтверждением.

Данные: **API** или **mock**. Пагинация на клиенте.

### Какие данные хранит

| Поле в интерфейсе | Обязательно | Пояснение                          |
| ----------------- | ----------- | ---------------------------------- |
| Наименование      | да          | название статуса (до 255 символов) |

### Связи с другими разделами

- **Используется в:** [текущие дела брокера](../broker.md) — статус выбирают в карточке дела.
- От других справочников не зависит.
