# Бренды

Задуманный справочник **брендов**. В текущей версии ЛК **не реализован**: страница показывает баннер «Раздел в разработке», пункт **скрыт из подменю** справочников.

Маршрут: `/directories/brands` (доступен по прямой ссылке) · В меню: нет

См. также: [обзор раздела](./README.md), [претенденты](./applicants.md).

---

## Общее описание справочника

### Статус

| Что              | Сейчас                |
| ---------------- | --------------------- |
| Для пользователя | баннер «в разработке» |
| CRUD             | нет                   |
| Данные / API     | нет                   |
| В навигации      | скрыт                 |

### Зачем планировался

Отдельный список брендов (торговых марок), отличный от [претендентов](./applicants.md). Сейчас роль «названия бренда / организации» частично закрывает поле названия у претендента — нужна продуктовая развилка: оставить заглушку, вырезать или реализовать отдельно.

### Что важно при планировании

- UI CRUD и бэкенд-контракт не сделаны.
- Прямая ссылка открывает только баннер; без реализации экрана вывод в меню ничего не даст.
